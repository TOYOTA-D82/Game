# 綁腳塔 Chained Tower

Roblox 合作跑酷闖關：雙人用腳鐐綁在一起、四人一起綁在中間的鐵球上。兩個世界各 8 關，**關卡路線每天自動換新**，每天比過關數和總時間，排名換積分，前三名有 24 小時限定獎勵。

- **每天都有新挑戰**：16 關的路線每天 UTC 0 點（台灣早上 8 點）全部換新，每天從第 1 關重新開始。全部跑完大約 20 到 30 分鐘，可以放鬆，遊玩時間也可以控制。
- **不用一直更新**：路線依日期自動產生、排名自動結算、節日活動依日期自動開關、每日任務自動輪替。
- **不買也能過**：自動測試模擬 60 天、共 960 條每日路線，100% 不靠道具可通關。
- 新手教學請看 [`新手教學.md`](新手教學.md)。

---

## 一、怎麼打開

1. 安裝 [Roblox Studio](https://create.roblox.com/)。
2. 雙擊 `ChainedTower.rbxl`，或在 Studio 裡用 File → Open from File 開啟。
3. 按 **Play**（F5）就能玩。大廳、世界和關卡都是程式自動蓋的，編輯模式下看到的是空地，屬於正常現象。

**測試雙人或四人模式**：上方選單 **Test → Clients and Servers**，玩家數選 2 或 4，按 Start。每個視窗是一個玩家，一起進組隊世界，站上同一道關卡門前的踏板。

**測試購買**：還沒填商品 ID 前，在 Studio 裡按任何購買按鈕都會**免費拿到**。

**測試關卡**：在 Studio 裡 16 關全部自動解鎖（`Config.StudioUnlockAll`）；正式上線後每天要從第 1 關開始。

## 二、玩法

### 兩個世界、各 8 關

大廳有兩道傳送門，各通往一座浮空島，島上有 8 道關卡門。

| 關卡 | 🧍 單人世界「天空群島」 | 🔗 組隊世界「鎖鏈群島」 |
|---|---|---|
| 1 | 🌿 草原 | 🌴 叢林（急流） |
| 2 | 🏜️ 沙漠（逆向輸送帶） | 🌋 火山（岩漿燒全隊） |
| 3 | ❄️ 冰原（地板會滑） | ⚓ 海港（急流、移動平台） |
| 4 | 🍭 糖果樂園 | 🏭 工廠（輸送帶、旋轉棒） |
| 5 | 🪐 外太空（低重力） | 🏰 暴風城堡 |
| 6 | 🏖️ 海灘 | 🏔️ 雪山（地板會滑） |
| 7 | 💎 水晶洞穴 | 🏴‍☠️ 海盜船 |
| 8 | ☁️ 雲端城 | 🌃 霓虹城（岩漿） |

- 每一關的天空、光線、霧色、平台材質和兩旁的風景都不一樣，**風格永遠固定**，但**路線每天換**：每天從該主題的關卡池抽出不同的組合（第 1、2 關 4 段，第 3 到 5 關 5 段，第 6 到 8 關 6 段）。
- 平台厚 2 格；最窄的地方單人 3 格、組隊 4 格。

### 每日挑戰和排行榜

| 規則 | 說明 |
|---|---|
| 每天重新開始 | 每天第 1 關開放，通過一關才開下一關（只算今天） |
| 計時 | 進關卡開始由伺服器計時，畫面上方顯示「⏱ 時間」，作弊改不了 |
| 今日排名 | 先比**今天過了幾關**，同樣關數再比**總時間**（每關取今天最快的一次）。可以回頭重跑前面的關卡刷新最佳時間 |
| 排行榜 | 大廳左牆「今日單人」、右牆「今日組隊」、出生點後面「積分總榜」；兩座世界島的關卡門上方也有今日排行 |
| 每日積分 | 隔天結算：第 1 名 100、第 2 名 80、第 3 名 65、第 4 到 10 名 55 到 25；11 到 25 名 15；26 到 50 名 10；51 到 100 名 6；100 名外有過關也有 3 分。積分永久累積 |
| 前三名獎勵（24 小時） | 🥇 冠軍：頭上「👑 #1」、冠軍專屬特效、金幣 ×2 / 🥈 亞軍：「🥈 #2」、銀色特效、金幣 ×1.5 / 🥉 季軍：「🥉 #3」、銅色特效、金幣 ×1.25 |
| 單人、組隊分開 | 兩個世界各自排名、各自發積分和獎勵 |
| 結算方式 | 玩家下次進遊戲時自動結算（之後每 5 分鐘再檢查一次），不需要有伺服器在半夜開著 |

### 單人和組隊

| | 🧍 單人世界 | 🔗 組隊世界 |
|---|---|---|
| 進入方式 | 走進關卡門 | 門前有兩個踏板：橘色雙人（2 人、3 秒後出發）、紫色四人（2 到 4 人，滿 4 人 3 秒、不滿 10 秒後出發） |
| 鎖鏈 | 沒有 | 雙人腳鐐（鏈長 12 格）；四人綁在中間的鐵球上（不能離鐵球超過 14 格） |
| 掉下去 | 回檢查點 | 吊在鎖鏈上：**自己會慢慢往上爬**，按住跳躍或畫面上的「⬆ 爬上去」大按鈕爬更快，爬到邊緣會自動翻上平台；站著的隊友只會被輕輕拖動，往反方向走就能把人拉上來。**全隊都沒站在地上超過 2.5 秒**才失敗 |
| 碰到岩漿 | 回檢查點 | 火順著鎖鏈燒到全隊，一起重來 |
| 金幣 | ×1 | 雙人 ×1.5、四人 ×2 |
| 排行榜 | 大廳左牆「今日單人」 | 大廳右牆「今日組隊」 |

出發時會跳出該關的規則卡，畫面上方一直顯示目前在哪一關、哪一段。

### 三種道具

| 道具 | 按鍵 | 效果 | 每天免費 |
|---|---|---|---|
| 🔓 解除束縛 | Q | 全隊掙脫鎖鏈 12 秒。時間到時，鎖鏈把落後的人拉回爬最高的隊友身邊 | 2 次（VIP +2、Premium 會員 +1） |
| 🔨 破壞錘 | E | 把前方有 🔨 記號的障礙炸飛，12 秒後會長回來 | 1 次（VIP +1） |
| ⏭ 跳過 | 按鈕 | 全隊直接跳到下一段（最後一段不能跳） | 無 |

有 🔨 記號的東西就是**關卡本身的障礙**，炸掉是給跳不過去的人用的：

- **跨欄**：長木板中間擋著木箱，要跳過去。
- **窄橋上的木樁**（較難的關卡）：在窄橋上跳過木樁。
- **旋轉棒**：會把人掃下去的紅色棒子。
- **繞路牆**：擋住直路的高牆，要從外圍的小踏石繞過去。

每個可跳的障礙都經過自動測試：高度不超過 5 格（角色能跳 7 格高），前後也有助跑和落地的空間。

## 三、付費設計（為什麼這樣定價）

照「先免費、再便宜、再划算」的順序，一步一步讓玩家習慣付費：

1. **每天免費**：每天送 2 個解除束縛、1 個破壞錘，讓所有人先體驗到好處。
2. **第一次付費門檻很低**：新手禮包 R$25 可以拿到 10 個解除束縛、5 個破壞錘和彩虹特效，每人限買一次。免費次數用完時，會優先推這個。
3. **小包裝**：解除束縛 ×5 R$19、破壞錘 ×3 R$25。
4. **大包裝比較划算**：解除束縛 ×20 R$59、破壞錘 ×12 R$79。
5. **VIP R$299**：永久金幣 2 倍、每天多送道具、金色名牌。是最貴的選項，讓其他價格看起來便宜。
6. **跑步特效**：火焰 R$99、閃電 R$129、銀河 R$199，別人都看得到。另外也可以用金幣買樹葉、泡泡、黃金特效。
7. **跳過一段 R$15**：同一段失敗 3 次才會跳出提示，不會一進遊戲就推銷。

**被動收入（上架後不用管）**：
- **Premium 分潤**：Premium 會員在你遊戲裡玩越久，Roblox 自動付你越多。
- **私人伺服器**：到 Creator Dashboard 打開，玩家每月付費開房間（建議 R$100 至 R$200）。

**符合 Roblox 規範**：沒有抽獎和隨機寶箱，沒有假的「限時」或「快賣完」，也不用催促話術。

## 四、上架步驟

### 1. 發布

1. Studio：**File → Publish to Roblox** → Create new experience → 名稱填 `Chained Tower 綁腳塔`。
2. **Home → Game Settings → Security** → 打開 **Enable Studio Access to API Services**（存檔和排行榜才會運作）。
3. 同一頁的 **Monetization** 可以打開 **Private Servers**。

### 2. 建立商品

到 [Creator Dashboard](https://create.roblox.com/dashboard/creations) → 你的遊戲 → **Monetization**：

**Passes**（建 4 個）：

| 名稱 | 價格 | 對應的設定名稱 |
|---|---|---|
| VIP | 299 | `VIP` |
| Fire Trail 火焰特效 | 99 | `FireTrail` |
| Lightning Trail 閃電特效 | 129 | `LightningTrail` |
| Galaxy Trail 銀河特效 | 199 | `GalaxyTrail` |

**Developer Products**（建 7 個）：

| 名稱 | 價格 | 對應的設定名稱 |
|---|---|---|
| Starter Pack 新手禮包 | 25 | `StarterPack` |
| Skip Section 跳過 | 15 | `Skip` |
| 5x Unchain | 19 | `Unchain5` |
| 20x Unchain | 59 | `Unchain20` |
| 3x Smash | 25 | `Smash3` |
| 12x Smash | 79 | `Smash12` |
| 1,000 Coins | 49 | `Coins1000` |

商品圖可以先用 `art/icon-512.png`。

### 3. 填入商品 ID

1. Studio 左側 **Explorer → ReplicatedStorage → Shared → Config**，雙擊打開。
2. 把每個商品的 ID 填到 `id = 0` 的位置。例如 `VIP = { id = 123456789, price = 299 }`。
3. 再按一次 **File → Publish to Roblox**。

### 4. 上傳圖片、填問卷、公開

1. Dashboard → **Places → Thumbnails & Icons**：圖示上傳 `art/icon-512.png`，封面上傳 `art/thumbnail-1920x1080.png`。
2. **Audience → Questionnaire**：填內容成熟度問卷（必填）。這款遊戲沒有暴力血腥，也沒有隨機付費獎勵。
3. 把遊戲從 **Private** 改成 **Public**。

### 5. 宣傳

用 Studio 錄影（或任何螢幕錄影工具）錄這幾種畫面，剪成 15 至 30 秒的短影音，上傳到 TikTok、YouTube Shorts、IG Reels，說明欄放遊戲連結：

- 雙人被腳鐐拉著一起從高處掉下去
- 一個人踩到岩漿，火沿著鎖鏈燒過全隊
- 隊友被急流沖下去，大家拚命往回拉
- 跳不過木箱，一錘把它炸飛
- 隊友吊在鎖鏈上，被大家拚命拉上來
- 四人被鐵球拖著跑

## 六、想調整數值

全部集中在 `src/shared/Config.luau`（Studio 裡是 `ReplicatedStorage → Shared → Config`），例如：

- `Config.FirstClearBonus`：每天第一次通過某關的額外金幣
- `Config.DailyRankPoints`、`Config.DailyRankBands`：每個名次給幾分
- `Config.DailyRewards`：前三名的獎勵（金幣倍率、特效、幾小時）
- `Config.ChainDragSpeed`、`Config.ClimbSpeed`、`Config.AutoClimbSpeed`：鎖鏈自救的難易度
- `Config.StudioUnlockAll`：Studio 測試時是否全部關卡解鎖
- 關卡本身（主題顏色、天空、關卡池、難度）在 `src/shared/Themes.luau`
- `Config.Modes.duo.chainLength`：腳鐐長度
- `Config.Daily`：每天送幾個免費道具
- 商品價格、特效顏色、活動日期

## 給開發者

```
src/shared/   Config（數值）、Themes（兩個世界和 16 關的設定）、Course（每日關卡算法）、
              Ranking（排名分數和積分）、Strings（中英文）、Calendar（日期）
src/server/   Main（啟動）、Game（關卡/組隊/鎖鏈/檢查點/道具）、World（蓋大廳、世界島和關卡）、
              Data（存檔）、Shop（購買）、Progress（金幣/任務/特效/排行榜）、Net（連線）
src/client/   Main（啟動）、Ambience（每關的天空和重力）、Chains（鎖鏈物理與畫面、跳板、
              水流、移動平台）、UI（介面）
tests/        Lune 測試
```

- 重新打包：`rojo build -o ChainedTower.rbxl`（需要 [Rojo](https://rojo.space/)）
- 邊改邊同步到 Studio：`rojo serve`，再用 Studio 的 Rojo 外掛連線
- 跑測試：`tests/run.sh`（需要 [Lune](https://lune-org.github.io/docs)）
  - 用正式的 Luau 編譯器檢查所有檔案語法
  - 模擬 60 天的每日路線（16 關 × 60 天 = 960 條），確認每條都能**不靠道具通關**、每個可炸障礙都跳得過去、移動平台接得上、平台夠寬（單人 3 格、組隊 4 格），而且每天真的會換
  - 排名分數：過關數優先、時間其次；名次給分只會遞減
  - 驗證節日日期、每日任務
  - 用 Roblox 物件規則實際蓋出大廳、兩座世界島和全部 16 關
- 語法檢查：`selene src`
