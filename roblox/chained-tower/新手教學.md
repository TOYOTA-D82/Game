# 綁腳塔：新手完整教學（從零到上架賺錢）

這份教學假設你**完全沒用過 Roblox Studio**。照順序一步一步做就好，每一步都會告訴你「做完應該看到什麼」。

> 💡 **畫面跟我寫的不一樣怎麼辦？**
> Roblox Studio 常常改版，按鈕位置可能會變。找不到某個按鈕時，用 Studio 右上角的**搜尋框**打功能名稱（例如 `Publish`、`Game Settings`）就能找到。

---

## 先搞懂：單人和組隊差在哪

這款遊戲有兩種玩法，規則完全不一樣：

| | 🧍 單人（藍色踏板） | 🔗 組隊：雙人（橘色）／四人（紫色） |
|---|---|---|
| 鎖鏈 | 沒有，自由行動 | 雙人用腳鐐綁住；四人一起綁在中間的鐵球上 |
| 掉下去 | 自己馬上回檢查點 | 吊在鎖鏈上，按住跳躍往上爬；隊友可以把你拉上來。**全隊都掉下去**才失敗 |
| 碰到岩漿 | 自己回檢查點 | 火順著鎖鏈**燒到全隊**，一起回檢查點 |
| 急流 | 被沖下去就回檢查點 | 被沖下去會吊在鏈上，隊友頂住拉回來 |
| 金幣 | ×1 | 雙人 ×1.5、四人 ×2 |
| 排行榜 | 大廳**左邊**牆上的「單人排行榜」 | 大廳**右邊**牆上的「組隊排行榜」 |
| 能用的道具 | 🔨 破壞錘、⏭ 跳過 | 🔓 解除束縛、🔨 破壞錘、⏭ 跳過 |
| 每日任務 | 一般任務 | 一般任務，加上「組隊爬 N 段」「組隊通關」 |

出發時畫面中間會跳出這個模式的**規則卡**，畫面上方也會一直顯示目前是 [單人]、[雙人] 還是 [四人]。

## 1. 準備工作（約 15 分鐘）

**你需要：**
- 一台**電腦**（Windows 或 Mac）。手機和平板做不了，Roblox Studio 只有電腦版。
- 一個 **Roblox 帳號**。沒有的話到 <https://www.roblox.com/> 免費註冊。
- **費用：0 元**。Studio、發布遊戲、建立商品全部免費。

**建議先做（之後領錢一定要用到）：**
- 到 Roblox 網站右上角 ⚙️ → **Settings（設定）** → **Account Info（帳號資訊）**，把 **Email 驗證**完成。

---

## 2. 下載遊戲檔

1. 用電腦瀏覽器打開這個連結（要先登入你的 GitHub 帳號）：
   **<https://github.com/toyota-d82/game/raw/claude/relaxed-mendel-nv0kt2/roblox/chained-tower/ChainedTower.rbxl>**
2. 瀏覽器會下載一個叫 `ChainedTower.rbxl` 的檔案，存到「下載」資料夾。

**同時把圖片也下載下來**（第 10、12 步上傳會用到）：
1. 打開：**<https://github.com/toyota-d82/game/archive/refs/heads/claude/relaxed-mendel-nv0kt2.zip>**
2. 會下載一個 ZIP 壓縮檔，在檔案上按右鍵 → **解壓縮**。
3. 圖片在解壓縮後的 `roblox/chained-tower/art/` 資料夾：
   - `icon-512.png`：遊戲圖示
   - `thumbnail-1920x1080.png`：遊戲封面
   - `shop/` 資料夾：11 張商品圖

✅ **做完應該看到**：下載資料夾裡有 `ChainedTower.rbxl`，和一個解壓縮後的資料夾。

## 3. 安裝 Roblox Studio

1. 打開 <https://create.roblox.com/>。
2. 按右上角 **Start Creating（開始創作）**，會下載 Studio 安裝程式。
3. 打開安裝程式，等它裝完（大約 2 到 5 分鐘）。
4. Studio 打開後，用你的 Roblox 帳號登入。

✅ **做完應該看到**：Studio 的首頁，上面有很多遊戲範本（Baseplate、Obby 之類的）。

---

## 4. 打開遊戲、認識畫面

1. 在 Studio 裡按左上角 **File（檔案）** → **Open from File...（從檔案開啟）**。
   - 也可以直接在下載資料夾**雙擊** `ChainedTower.rbxl`。
2. 選剛剛下載的 `ChainedTower.rbxl` → 開啟。

**你會看到一片空白的天空，這是正常的。** 大廳和高塔都是「按下開始後才由程式自動蓋出來」的。

### 先打開兩個重要的視窗

上方選單 **View（檢視）** → 點這兩個：
- **Explorer（瀏覽器）**：右邊會出現遊戲的所有內容，像資料夾一樣。
- **Output（輸出）**：下方會出現一個訊息欄。**遊戲出錯時，紅字會出現在這裡**。

✅ **做完應該看到**：右邊有 Explorer，裡面有 `Workspace`、`ReplicatedStorage`、`ServerScriptService` 等項目；下方有 Output 欄。

## 5. 測試一：自己一個人玩

1. 按上方的 **▶ Play（播放）**，或按鍵盤 **F5**。
2. 等幾秒，角色會出現在大廳。

### 照著這張清單一項一項檢查

| # | 做什麼 | 應該看到 |
|---|---|---|
| 1 | 看四周 | 草地、白色廣場、前方有大招牌「CHAINED TOWER 綁腳塔」，**左邊牆**是單人排行榜（藍色），**右邊牆**是組隊排行榜（紫色） |
| 2 | 看前方 | 3 個發光的踏板：藍色「單人」、橘色「雙人」、紫色「四人」，每個上方都寫著規則和金幣倍率 |
| 3 | 看畫面 | 上方有倒數「新塔倒數 9:xx」，左上有 🪙 金幣，左邊有「商店、特效、每日」按鈕 |
| 4 | 走到**藍色**踏板上 | 被傳送到高塔底部，畫面中間跳出藍色的「🧍 單人模式」規則卡，上方顯示「[單人] 第 0 / 10 段」 |
| 5 | 往前跳到下一個綠色平台 | 段數變成 1，金幣增加 |
| 6 | 故意掉下去 | 被傳回剛剛的綠色平台 |
| 7 | 有岩漿的關卡，故意踩進岩漿 | 被傳回檢查點 |
| 8 | 看右下角 | 有 🔨 破壞錘和 ⏭ 跳過按鈕（單人沒有 🔓 解除束縛） |
| 9 | 走到有 🔨 記號的木箱前面，按 **E** | 木箱炸開碎片亂飛，12 秒後會長回來 |
| 10 | 看 Output 欄 | **不應該有紅字**（黃字警告沒關係，例如存檔相關的黃字在發布前是正常的） |

**結束測試**：按上方的 **■ Stop（停止）**，或按 **Shift + F5**。

> ⚠️ **很重要：在 Play 模式裡做的任何修改，按 Stop 之後都會消失。** 改設定一定要先按 Stop 再改。

## 6. 測試二：雙人和四人模式

Studio 可以一次開好幾個視窗，假裝有好幾個玩家。

1. 先確認已經按 Stop 停止遊戲。
2. 上方選單切到 **Test（測試）** 分頁。
3. 找到 **Clients and Servers（用戶端和伺服器）** 區塊：
   - 下拉選單選 **2 Players**（測四人就選 4）。
   - 按 **Start（開始）**。
4. 會跳出好幾個視窗：一個是伺服器，另外每個玩家各一個。點哪個視窗，就是在控制哪個玩家。

> 電腦比較慢的話，開 4 個玩家可能會卡，先測 2 個就好。

### 雙人檢查清單

| # | 做什麼 | 應該看到 |
|---|---|---|
| 1 | 兩個玩家都走上**橘色**踏板 | 踏板上方顯示「3 秒後出發」，然後兩人一起被傳到高塔，跳出紫色的「🔗 組隊模式」規則卡，上方顯示「[雙人]」 |
| 2 | 看兩人腳邊 | 中間連著一條灰色鎖鏈，鬆的時候會往下垂 |
| 3 | 一個人往前跑 | 鏈子拉直、變紅，被拉回去 |
| 4 | 讓**玩家 A** 從平台邊緣跳下去，**玩家 B** 站著不動 | A 吊在鏈子上晃，畫面提示「按住跳躍往上爬」；B 被慢慢拖向邊緣，畫面提示「往反方向走」 |
| 5 | 吊著的 A 按住**空白鍵** | A 沿著鏈子往上爬 |
| 6 | B 往反方向走 | 把 A 拉上來 |
| 7 | 兩個人都跳下去 | 大約 2.5 秒後兩人一起回到檢查點，提示「全隊都掉下去了」 |
| 8 | 其中一人踩到岩漿 | 火從那個人燒到另一個人，鎖鏈變成發光的橘紅色，然後全隊重來 |
| 9 | 按 **Q**（解除束縛） | 鏈子消失 12 秒，可以分開走；時間到時落後的人被拉回隊友身邊 |
| 10 | 第 2 圈開始有藍色水道（急流） | 站上去會被往塔外沖，水面有白色浪花 |

### 四人檢查清單

| # | 做什麼 | 應該看到 |
|---|---|---|
| 1 | 2 到 4 個玩家走上**紫色**踏板 | 2 到 3 人時倒數 10 秒，滿 4 人時倒數 3 秒 |
| 2 | 看隊伍中間 | 有一顆黑色鐵球，每個人都有鎖鏈連到鐵球，地上有紫色圓圈表示活動範圍 |
| 3 | 一個人跑離鐵球 | 被拉回來 |

**結束測試**：在 Test 分頁按 **Cleanup（清除）**，或直接關掉所有跳出的視窗。

## 7. 測試三：商店和道具

還沒建立商品之前，**在 Studio 裡按購買不會扣錢，而是直接免費給你**，方便測試。

| # | 做什麼 | 應該看到 |
|---|---|---|
| 1 | 按左邊 🛒 **商店** | 商店視窗出現，有新手禮包、VIP、各種道具包、特效。「解除束縛」標著「（組隊限定）」 |
| 2 | 按「新手禮包」的價格按鈕 | 跳出「感謝購買」，右下角道具數量增加，新手禮包從商店消失（限購一次） |
| 3 | 按 VIP 的價格 | 頭上出現金色「👑 VIP」名牌，按鈕變成「已擁有」 |
| 4 | 按 ✨ **特效**，選彩虹或火焰 → 裝備 | 跑步時身後出現彩色拖尾 |
| 5 | 按 📅 **每日** | 看到 3 個今日任務和進度 |
| 6 | 把今天的免費道具用完（解除束縛 2 次、破壞錘 1 次），再按一次 | 跳出「用完了，要再買一些嗎？」的購買提示 |
| 7 | 在同一段故意失敗 3 次 | 跳出「卡關了嗎？幫全隊跳過這一段」 |

### 小技巧：想快點看到「換新塔」

正常要等 10 分鐘才會換新塔。測試時可以暫時改短：

1. 先按 **Stop**。
2. Explorer → **ReplicatedStorage** → **Shared** → 雙擊 **Config**。
3. 找到這一行：
   ```lua
   Config.RoundSeconds = 10 * 60
   ```
   改成：
   ```lua
   Config.RoundSeconds = 60
   ```
4. 按 Play，1 分鐘後就會換新塔。
5. **測完記得改回 `10 * 60`！**

## 8. 發布到 Roblox

1. 按 **File（檔案）** → **Publish to Roblox（發布到 Roblox）**。
2. 第一次發布會跳出視窗，照這樣填：
   - **Name（名稱）**：`Chained Tower 綁腳塔`
   - **Description（說明）**：可以直接複製下面這段：
     ```
     Climb a tower CHAINED to your friends! 🔗
     Duo: ankle chain. Squad: 4 players chained to an iron ball.
     Fall off and you hang on the chain — your team must pull you up!
     Touch lava and the fire burns the whole chain 🔥
     Smash obstacles with the hammer 🔨  New tower every 10 minutes!

     和朋友綁在一起爬塔！掉下去會吊在鎖鏈上，要靠隊友把你拉上來！
     ```
   - **Genre（類型）**：選 **Obby & Platformer**（或類似的跑酷類型）
   - **Devices（裝置）**：電腦、手機、平板、主機**全部打勾**（玩家越多越好）
3. 按 **Create（建立）**。

### 打開存檔功能（一定要做）

1. **File** → **Game Settings（遊戲設定）**。
2. 左邊選 **Security（安全性）**。
3. 打開 **Enable Studio Access to API Services**。
4. 按右下角 **Save（儲存）**。

✅ **做完應該看到**：Studio 上方的標題變成你的遊戲名稱。到 <https://create.roblox.com/dashboard/creations> 可以看到你的遊戲（目前還是私人的，只有你能玩）。

## 9. 測試四：存檔

發布後存檔才會運作，現在來測試：

1. 按 **Play**，爬幾段賺一些金幣，記下金幣數字。
2. 買一個用金幣買的特效（例如樹葉 250 金幣，不夠的話就多爬幾段），裝備它。
3. 按 **Stop**，等 5 秒。
4. 再按一次 **Play**。

✅ **應該看到**：金幣數字和特效都還在。

❌ **如果金幣歸零**：回到第 8 步，確認 **Enable Studio Access to API Services** 有打開並按了 Save。

## 11. 把商品 ID 填進遊戲

### 方法 A（最簡單）：把 ID 傳給我

把記事本裡的 11 個 ID 直接貼給我，例如：
```
VIP = 123456789
FireTrail = 223456789
...
```
我會幫你填好，再給你一個新的遊戲檔。拿到後照[第 18 步](#18-我之後改了遊戲你要怎麼更新)更新就好。

### 方法 B：自己填

1. Studio 右邊 **Explorer** → **ReplicatedStorage** → **Shared** → 雙擊 **Config**。
2. 找到這一段：
   ```lua
   Config.GamePasses = {
   	VIP = { id = 0, price = 299 },
   ```
3. 把 `id = 0` 的 **0** 換成你複製的數字。例如：
   ```lua
   	VIP = { id = 123456789, price = 299 },
   ```
4. 11 個全部換完（4 個在 `Config.GamePasses`，7 個在 `Config.Products`）。
5. **小心不要刪到逗號 `,` 和大括號 `{ }`**。
6. 按 **File** → **Publish to Roblox** 再發布一次。

### 測試購買

按 **Play**，打開商店按任何一個購買：
- ✅ 應該跳出 Roblox 的購買視窗，上面寫 **This is a test purchase; your account will not be charged**（測試購買，不會扣錢）。

## 13. 填問卷、公開遊戲

### 13-1. 填內容問卷（必填，沒填不能公開）

1. 打開 <https://create.roblox.com/dashboard/creations> → 點你的遊戲。
2. 左邊選單找 **Audience（觀眾）** → **Maturity & Compliance（成熟度與合規）**，開始填問卷。
3. 照實回答。這款遊戲：
   - **沒有**血腥、暴力武器、恐怖內容
   - **沒有**隨機抽獎、隨機寶箱（paid random items）
   - **沒有**賭博
   - 只有卡通風格的跌落和岩漿
4. 送出。

### 13-2. 打開私人伺服器（額外的被動收入）

1. Studio → **File** → **Game Settings** → **Monetization（營利）**。
2. 打開 **Private Servers（私人伺服器）**，價格建議填 **100**（玩家每月付費）。
3. **Save**。

### 13-3. 改成公開

1. Studio → **File** → **Game Settings** → **Permissions（權限）**。
2. **Playability（可玩性）** 選 **Public（公開）**。
3. **Save**。

> 如果 Roblox 跳出要你驗證帳號（例如驗證 Email、手機或身分），照畫面指示完成即可。

✅ **做完應該看到**：到 Roblox 網站搜尋「Chained Tower」找得到你的遊戲（新遊戲剛公開，搜尋可能要等一陣子才出現，可以先用遊戲連結直接進）。

## 15. 宣傳

新遊戲沒有人推薦，就算做得好也很難被看到。最便宜有效的方法是**短影音**。

**怎麼錄影：**
- Windows：按 **Win + Alt + R** 開始／停止錄影（Xbox Game Bar）。
- Mac：按 **Cmd + Shift + 5** → 選「錄製螢幕」。

**錄這些畫面（越好笑越好）：**
- 兩人被腳鐐拉著，一起從高處摔下去
- 一個人踩到岩漿，火沿著鎖鏈燒過全隊
- 隊友被急流沖下去，大家拚命往回拉
- 跳不過木箱，一錘把它炸飛
- 四個人被鐵球拖著跑

**怎麼發：**
- 剪成 **15 到 30 秒**，直式（9:16）最好。
- 上傳到 **TikTok、YouTube Shorts、Instagram Reels**。
- 標題範例：「和朋友綁在一起爬塔，結果……😂」、「Roblox 最考驗友情的遊戲」
- 說明欄放遊戲連結，加上 `#roblox #robloxgame #obby`。
- 每週固定發 2 到 3 支，比一次發很多支有效。

## 16. 怎麼把 Robux 換成現金

Roblox 的官方換錢計畫叫 **DevEx（Developer Exchange）**。

**條件：**
- 滿 **13 歲**
- 帳號裡有至少 **30,000 個「賺來的」Robux**（買來的不算），大約可以換 **114 美元**
- Email 已驗證、帳號沒有違規

**怎麼申請：** 存到 30,000 之後，到 Roblox 網站的 Robux 頁面找 **Cash Out（提領）／DevEx**，照指示填資料（需要稅務資料和收款帳戶）。詳細規定看官方說明：<https://create.roblox.com/docs/production/monetization/developer-exchange>

> 遊戲賣出的錢，Roblox 會先扣手續費，你大約拿到售價的 **70%**。例如有人買了 R$100 的東西，你約得到 70 Robux。

## 17. 遇到問題怎麼辦

| 問題 | 解決方法 |
|---|---|
| 按 Play 後什麼都沒有，一片空白 | 看 Output 欄有沒有紅字，把紅字整段複製給我 |
| 金幣每次都歸零 | 第 8 步的 **Enable Studio Access to API Services** 沒打開 |
| 按購買沒反應 | 已經填了商品 ID，但通行證沒打開「Item for Sale」（第 10-1 步第 5 點） |
| 排行榜一直是空的 | 正常，要有人通關後等約 2 分鐘才會更新；而且要發布後才會運作 |
| 某一關真的跳不過去 | 截圖給我，告訴我是第幾段、長什麼樣子 |
| 鎖鏈拉力太強或太弱 | 告訴我是哪一種，或自己改 `Config` 裡的 `ChainDragSpeed`（被拖的速度，目前 6）和 `ClimbSpeed`（往上爬的速度，目前 9） |

### 怎麼把錯誤訊息給我

1. 在 **Output** 欄找到**紅色**的文字。
2. 用滑鼠選取整段紅字 → 按右鍵 → **Copy（複製）**。
3. 貼給我，並說明你當時在做什麼（例如「兩個人走上橘色踏板之後」）。
