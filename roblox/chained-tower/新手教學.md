# 綁腳塔：新手完整教學（從零到上架賺錢）

這份教學假設你**完全沒用過 Roblox Studio**。照順序一步一步做就好，每一步都會告訴你「做完應該看到什麼」。

> 💡 **畫面跟我寫的不一樣怎麼辦？**
> Roblox Studio 常常改版，按鈕位置可能會變。找不到某個按鈕時，用 Studio 右上角的**搜尋框**打功能名稱（例如 `Publish`、`Game Settings`）就能找到。

## 先搞懂：遊戲長什麼樣子

```
大廳 ──🧍 藍色傳送門──▶ 單人世界「天空群島」：草原 → 沙漠 → 冰原 → 糖果樂園 → 外太空 → 海灘 → 水晶洞穴 → 雲端城
     └─🔗 紫色傳送門──▶ 組隊世界「鎖鏈群島」：叢林 → 火山 → 海港 → 工廠 → 暴風城堡 → 雪山 → 海盜船 → 霓虹城
```

- 每個世界是一座浮空島，島上有 **8 道關卡門**，走進門就開始那一關。
- **每天換新路線**：每天台灣早上 8 點，16 關的**路線全部換新**（風格不變），大家從第 1 關重新開始，過一關才開下一關。全部跑完大約 20 到 30 分鐘。大廳的「🔄 路線更新倒數」看板會倒數。
- **⚡ 每日挑戰**：大廳中間的金色傳送門。每天換場景的超長單人關（16 段、所有機關、最高難度、不能用道具），積分很多；當天最快的前 3 名拿 24 小時的頭上稱號（挑戰王、亞軍、季軍）。
- **大廳和關卡是分開的空間**：在哪裡就只看到哪裡，進出時有黑幕過場和大字標題。
- **今日積分**：今天通過任何 1 關後，**每分鐘自動加分**（在大廳、站著不動、離線都算；離線每天最多補 8 小時）。每分鐘加幾分看你**昨天的最終名次**：第 1 名 +10、第 2 名 +9、第 3 名 +8、第 4–10 名 +7、第 11–50 名 +6、第 51–100 名 +5、其他人 +4。排行榜不會同分：分數一樣時，先達到的人排前面。過檢查點、通關還有額外加分。每天早上 8 點歸零。
- **本週積分**：今日積分同時加進本週積分，每週一早上 8 點歸零。
- **每日前三名（獎勵 1 天）**：頭上皇冠或名牌、專屬跑步特效、金幣加成（冠軍 ×2、亞軍 ×1.5、季軍 ×1.25）。
- **每週前十名（獎勵 1 週）**：會拍動的翅膀。冠軍是金色天使翅膀加光環，第 2 名銀翼、第 3 名銅翼、第 4 到 10 名精靈翅膀。
- 這些獎勵**買不到**，跟商店分開，時間到就消失。
- 每一關的天空、光線、顏色、兩旁的風景都不一樣；冰原和雪山地板會滑，外太空重力比較低。
- 組隊世界的每道門前有兩個踏板：橘色是雙人、紫色是四人。

### 單人和組隊差在哪

| | 🧍 單人世界 | 🔗 組隊世界：雙人／四人 |
|---|---|---|
| 鎖鏈 | 沒有，自由行動 | 雙人用腳鐐綁住；四人一起綁在中間的鐵球上 |
| 掉下去 | 自己馬上回檢查點 | 吊在鎖鏈上：**自己會慢慢往上爬**，按住跳躍或「⬆ 爬上去」大按鈕爬更快，爬到邊緣會自動翻上去；隊友往反方向走也能拉你上來。**全隊都掉下去**才失敗 |
| 碰到岩漿 | 自己回檢查點 | 火順著鎖鏈**燒到全隊**，一起回檢查點 |
| 急流 | 被沖下去就回檢查點 | 被沖下去會吊在鏈上，隊友頂住拉回來 |
| 金幣 | ×1 | 雙人 ×1.5、四人 ×2 |
| 積分 | 今天通關 1 關後每分鐘自動加分（昨天名次越好越多，離線也算）、過檢查點和通關加分 | 一樣，再加上雙人 ×1.2、四人 ×1.4（同一個排行榜） |
| 能用的道具 | 🔨 破壞錘、⏭ 跳過 | 🔓 解除束縛、🔨 破壞錘、⏭ 跳過 |
| 每日任務 | 一般任務 | 一般任務，加上「組隊爬 N 段」「組隊通關」 |

出發時畫面中間會跳出這個模式的**規則卡**，畫面上方也會一直顯示目前是 [單人]、[雙人] 還是 [四人]。

## 1. 準備工作（約 15 分鐘）

**你需要：**
- 一台**電腦**（Windows 或 Mac）。手機和平板做不了，Roblox Studio 只有電腦版。
- 一個 **Roblox 帳號**。沒有的話到 <https://www.roblox.com/> 免費註冊。
- **費用：0 元**。Studio、發布遊戲、建立商品全部免費。

**建議先做（之後領錢一定要用到）：**
- 到 Roblox 網站右上角 ⚙️ → **Settings（設定）** → **Account Info（帳號資訊）**，把 **Email 驗證**完成。

## 2. 下載遊戲檔

1. 用電腦瀏覽器打開這個連結（要先登入你的 GitHub 帳號）：
   **<https://github.com/toyota-d82/game/raw/claude/relaxed-mendel-nv0kt2/roblox/chained-tower/ChainedTower.rbxl>**
2. 瀏覽器會下載一個叫 `ChainedTower.rbxl` 的檔案，存到「下載」資料夾。

**同時把圖片也下載下來**（第 10、12 步上傳會用到）：
1. 打開：**<https://github.com/toyota-d82/game/archive/refs/heads/claude/relaxed-mendel-nv0kt2.zip>**
2. 會下載一個 ZIP 壓縮檔，在檔案上按右鍵 → **解壓縮**。
3. 圖片在解壓縮後的 `roblox/chained-tower/art/` 資料夾：
   - `icon-512.png`：遊戲圖示
   - `thumbnail-1920x1080.png`：遊戲封面
   - `shop/` 資料夾：11 張商品圖

✅ **做完應該看到**：下載資料夾裡有 `ChainedTower.rbxl`，和一個解壓縮後的資料夾。

## 3. 安裝 Roblox Studio

1. 打開 <https://create.roblox.com/>。
2. 按右上角 **Start Creating（開始創作）**，會下載 Studio 安裝程式。
3. 打開安裝程式，等它裝完（大約 2 到 5 分鐘）。
4. Studio 打開後，用你的 Roblox 帳號登入。

✅ **做完應該看到**：Studio 的首頁，上面有很多遊戲範本（Baseplate、Obby 之類的）。

---

## 4. 打開遊戲、認識畫面

1. 在 Studio 裡按左上角 **File（檔案）** → **Open from File...（從檔案開啟）**。
   - 也可以直接在下載資料夾**雙擊** `ChainedTower.rbxl`。
2. 選剛剛下載的 `ChainedTower.rbxl` → 開啟。

**你會看到一片空白的天空，這是正常的。** 大廳、兩個世界和 10 個關卡都是「按下開始後才由程式自動蓋出來」的。

### 先打開兩個重要的視窗

上方選單 **View（檢視）** → 點這兩個：
- **Explorer（瀏覽器）**：右邊會出現遊戲的所有內容，像資料夾一樣。
- **Output（輸出）**：下方會出現一個訊息欄。**遊戲出錯時，紅字會出現在這裡**。

✅ **做完應該看到**：右邊有 Explorer，裡面有 `Workspace`、`ReplicatedStorage`、`ServerScriptService` 等項目；下方有 Output 欄。

## 5. 測試一：自己一個人玩

1. 按上方的 **▶ Play（播放）**，或按鍵盤 **F5**。
2. 等幾秒，角色會出現在大廳。

### 照著這張清單一項一項檢查

| # | 做什麼 | 應該看到 |
|---|---|---|
| 1 | 看四周 | 一座浮在空中的草地島：中央有噴泉、四周有樹和路燈；左前方是「玩法說明」看板；上方顯示「大廳」 |
| 1b | 往兩側看 | 西側是「今日積分」看板、東側是「本週積分」看板；左後方是擺著天使翅膀、光環和皇冠的**獎勵展示台**（翅膀會灑亮光）；右後方是三層的**名人堂頒獎台** |
| 2 | 看前方 | 三道發光的拱門，上方各有一個發光圓環：藍色「🧍 單人世界」、紫色「🔗 組隊世界」、中間稍後面的金色「⚡ 每日挑戰」 |
| 2b | 看出生點右前方 | 「🔄 路線更新倒數」看板：大大的倒數時間（到台灣早上 8 點），下面寫「⚡ 今日挑戰：某個場景」和目前第一名（還沒人完成時寫「快來搶第一」） |
| 3 | 走進**藍色**拱門 | 畫面變黑、出現大字「天空群島（單人世界）」，然後到一座浮空島；**大廳完全看不到了**，天空變成早晨的藍色 |
| 4 | 看島上 | 你站在**第 1 關門前**（不是站在門的框裡）。一排 8 道關卡門，每道上面寫「第 N 關・名稱」；門的上方有今日排行榜；身後有「⬅ 回大廳」的白色拱門 |

| 5c | 走進**第 2 關（沙漠）** | 這關是**爬塔**：繞著中間的金字塔螺旋往上爬 |
| 5b | 看左上角 | 金幣下面有「⭐ 今日 0・本週 0（今天通關 1 關，就能每分鐘自動加分）」。等你通過第 1 關後會變成「（4 分，xx 秒後）」，倒數到 0 時跳出「+4 ⭐」（Studio 裡沒有昨天的名次，所以是 +4） |
| 6 | 往前跳到轉角的檢查點（有發光邊框和小旗子） | 段數變成 1，金幣增加，跳出「+5 ⭐」；那支旗子和邊框**變綠色** |
| 7 | 故意掉下去 | 被傳回剛剛的檢查點 |
| 8 | 遇到移動平台 | 平台來回滑動，站上去會被載著走 |
| 9 | 看右下角 | 有 🔨 破壞錘和 ⏭ 跳過按鈕（單人沒有 🔓 解除束縛） |
| 10 | 到第 3 關以後，遇到有 🔨 記號的高牆 | 跳不過去。試試從外側的小踏石或岩階繞過去，或面向牆按 **E** 炸掉，碎片亂飛，12 秒後會長回來 |
| 10b | 碰到紅色的旋轉棒 | 被**打飛**出去，畫面顯示「被旋轉棒打飛啦！」 |

| 10d | 踩到裂開的灰色碎裂磚 | 變橘色、晃一下，大約 1 秒後碎掉，4 秒後長回來 |
| 10e | 踩上淺藍色的滑行冰面 | 會一直往前滑，很難停下或轉彎；中間有破洞要小心 |
| 10f | 遇到衝過來的牆 | 橘色矮牆要跳過去，紅色半邊高牆要往旁邊躲；被撞到會被打飛 |
| 10g | 跳到遠處的山、樹、建築上 | 摸得到、不會穿過去；但站上去會被送回檢查點（不能抄捷徑） |
| 11 | 到終點的金色 🏆 平台 | 跳出「通關！用時 X:XX.X，+N ⭐、+N 金幣」和「解鎖新關卡：沙漠」，5 秒後黑幕過場回到浮空島，站在**第 2 關（沙漠）門前**；草原門上顯示你今天的最佳時間「✅ X:XX.X」 |
| 12 | 試試其他關卡 | **在 Studio 裡 16 關全部已經解鎖**，方便你每一關都試（正式上線後每天都要從第 1 關開始）。冰原和雪山地板會滑、外太空跳得特別高、沙漠有逆向的輸送帶 |
| 12b | 按 📅 **每日** | 最上面兩張卡：「今日進度」顯示單人和組隊今天過了幾關；「積分與獎勵」顯示今日和本週積分、多久後歸零、正在生效的獎勵 |
| 12c | 按 Tab 看玩家名單 | 每個人旁邊有「Today」（今日積分）和「Coins」 |
| 12c2 | 回大廳，走進中間的金色「⚡ 每日挑戰」 | 到「挑戰島」：一道金色的門寫「⚡ 今日挑戰：某場景」，左邊是「今日挑戰最快紀錄」看板，右邊是規則和倒數 |
| 12c3 | 走進金色的門 | 黑幕寫「⚡ 每日挑戰」和今天的場景；規則卡是金色的。路線有 16 段，岩漿、水流、飛來的牆、旋轉棒、輸送帶……都會出現 |
| 12c4 | 在挑戰裡按 E 或 ⏭ | 上方顯示「每日挑戰不能用道具，大家公平比速度！」，不會扣道具 |
| 12c5 | 跑到終點（可以先按「🚪 離開關卡」，之後再挑戰） | 「挑戰完成！用時 X:XX.X」和「今日新紀錄」，積分比一般關卡多。門上會顯示你今天的最佳時間 |
| 12d | 按左邊紫色的 📖 **說明** | 打開「遊戲說明手冊」，上面有 4 個分頁（怎麼玩／方塊／道具／積分）。按「🧱 方塊」，每一種方塊左邊的小方塊是它在遊戲裡的顏色；按 ✕ 或再按一次 📖 就會關掉。第一次進遊戲（還沒通關過）幾秒後，上方會跳一次「第一次玩嗎？按左邊 📖 說明看看」 |
| 13 | 看 Output 欄 | **不應該有紅字**（黃字警告沒關係，例如存檔相關的黃字在發布前是正常的） |

**結束測試**：按上方的 **■ Stop（停止）**，或按 **Shift + F5**。

> ⚠️ **很重要：在 Play 模式裡做的任何修改，按 Stop 之後都會消失。** 改設定一定要先按 Stop 再改。

## 6. 測試二：雙人和四人模式

Studio 可以一次開好幾個視窗，假裝有好幾個玩家。

1. 先確認已經按 Stop 停止遊戲。
2. 上方選單切到 **Test（測試）** 分頁。
3. 找到 **Clients and Servers（用戶端和伺服器）** 區塊：
   - 下拉選單選 **2 Players**（測四人就選 4）。
   - 按 **Start（開始）**。
4. 會跳出好幾個視窗：一個是伺服器，另外每個玩家各一個。點哪個視窗，就是在控制哪個玩家。

> 電腦比較慢的話，開 4 個玩家可能會卡，先測 2 個就好。

### 雙人檢查清單

| # | 做什麼 | 應該看到 |
|---|---|---|
| 1 | 兩個玩家都走進大廳的**紫色**拱門，再一起站上「第 1 關・叢林」門前的**橘色（雙人）**踏板 | 踏板上方顯示「3 秒後出發」，然後兩人一起被傳到叢林關卡，跳出「🔗 組隊模式」規則卡，上方顯示「[雙人]」 |
| 2 | 看兩人腳邊 | 中間連著一條灰色鎖鏈，鬆的時候會往下垂 |
| 3 | 一個人往前跑 | 鏈子拉直、變紅，被拉回去 |
| 4 | 讓**玩家 A** 從平台邊緣跳下去，**玩家 B** 站著不動 | A 吊在鏈子上晃，畫面提示「按住跳躍往上爬」；B 被慢慢拖向邊緣，畫面提示「往反方向走」 |
| 5 | A 什麼都不按 | A 會自己**慢慢**往上爬；A 的畫面中間出現黃色的「⬆ 爬上去」大按鈕 |
| 5b | A 按住**空白鍵**或「⬆ 爬上去」 | A 很快沿著鏈子往上爬，到邊緣會自動跳上平台 |
| 6 | B 往反方向走 | B 只被輕輕拖動，往反方向走就能把 A 拉上來 |
| 7 | 兩個人都跳下去 | 大約 2.5 秒後兩人一起回到檢查點，提示「全隊都掉下去了」 |
| 8 | 到**火山**關，其中一人踩到岩漿 | 火從那個人燒到另一個人，鎖鏈變成發光的橘紅色，然後全隊重來 |
| 8b | 遇到上面寫「👣 2」的透明承重磚 | 第 1 個人踩上去變「👣 1」，第 2 個人變「👣 0」，第 3 個人一踩就碎；四人隊伍要分左右兩塊走 |

### 小技巧：測試時全部關卡都已解鎖

在 Studio 裡測試時，16 關會**自動全部解鎖**，方便你每一關都試。這個設定**只在 Studio 有效**，正式上線的遊戲裡，玩家每天都要從第 1 關開始，過一關開一關。

如果你想在 Studio 裡體驗「今天從第 1 關開始」的感覺：
1. 先按 **Stop**。
2. Explorer → **ReplicatedStorage** → **Shared** → 雙擊 **Config**。
3. 找到 `Config.StudioUnlockAll = true`，把 `true` 改成 `false`。
4. 測完可以改回 `true`。

### 積分、排行榜、獎勵要怎麼測？

**每分鐘加分**在 Studio 裡就能測（上面第 5b 步）。**排行榜和獎勵**要用到 Roblox 的雲端資料庫，**發布之後才會運作**，要先完成[第 8 步](#8-發布到-roblox)的發布，並打開「API 存取」。

| 功能 | 怎麼測 | 應該看到 |
|---|---|---|
| 每分鐘加分還沒開 | 剛進遊戲、今天還沒通關 | 左上角寫「今天通關 1 關，就能每分鐘自動加分」，不會加分 |
| 每分鐘加分 | 通過第 1 關，然後在大廳站著不動 1 分鐘 | 「+4 ⭐」，今日和本週都加 4（站著不動也算）；按 📅 每日，積分卡寫「昨天沒進前 100 名 → 每分鐘 +4 ⭐」 |
| 名次越好加越多 | 發布後：今天玩到排行榜前幾名，**隔天**再進遊戲並通過 1 關 | 積分卡寫「昨天第 N 名 → 今天每分鐘 +X ⭐」（第 1 名 +10） |
| 離線加分 | 發布後：通過 1 關 → 離開遊戲 → 等 5 分鐘以上再進來 | 跳出「你離開的 N 分鐘裡獲得了 +X ⭐」（每天最多補 8 小時）。Studio 測試不會存檔，所以這項要發布後才測得到 |
| 今日／本週排行 | 發布後按 Play，玩幾分鐘，等 1 分鐘 | 大廳的「今日積分」「本週積分」看板出現你的名字和分數 |
| 每日獎勵 | **隔天**（台灣早上 8 點以後）再進遊戲 | 跳出「昨天你排第 N 名」；前三名會跳出「恭喜獲得 24 小時冠軍獎勵」，頭上出現皇冠或名牌，特效自動換成獎勵特效 |
| 每週獎勵 | **下週一**早上 8 點以後再進遊戲 | 跳出「上週你排第 N 名」；前十名背上出現會拍動的翅膀（發光羽緣、翅尖光痕、灑亮粉，跳起來會用力拍），冠軍還有發光的光環；大廳名人堂顯示上週前三名 |
| 獎勵到期 | 1 天後（每日）或 1 週後（每週） | 皇冠、特效、翅膀自動消失 |

> 💡 因為要等到隔天、隔週才結算，這部分最好上線後實際玩一段時間來確認。如果你一個人測，自己一定是第 1 名，可以直接看到冠軍獎勵。

## 13. 填問卷、公開遊戲

### 13-1. 填內容問卷（必填，沒填不能公開）

### 13-2. 打開私人伺服器（額外的被動收入）

用**網頁**設定就好，不用開 Studio（Studio 連不上 Roblox 時也能做）。選單名稱中英文都寫給你，畫面是哪一種語言就看哪一個。

✅ **做完應該看到**：到 Roblox 網站搜尋「Chained Tower」找得到你的遊戲（新遊戲剛公開，搜尋可能要等一陣子才出現，可以先用遊戲連結直接進）。

## 15. 宣傳

新遊戲沒有人推薦，就算做得好也很難被看到。最便宜有效的方法是**短影音**。

**怎麼錄影：**
- Windows：按 **Win + Alt + R** 開始／停止錄影（Xbox Game Bar）。
- Mac：按 **Cmd + Shift + 5** → 選「錄製螢幕」。

**錄這些畫面（越好笑越好）：**
- 兩人被腳鐐拉著，一起從高處摔下去
- 一個人踩到岩漿，火沿著鎖鏈燒過全隊
- 隊友被急流沖下去，大家拚命往回拉
- 爬不過高牆，一錘把它炸飛
- 四個人被鐵球拖著跑

**怎麼發：**
- 剪成 **15 到 30 秒**，直式（9:16）最好。
- 上傳到 **TikTok、YouTube Shorts、Instagram Reels**。
- 標題範例：「和朋友綁在一起爬塔，結果……😂」、「今天終於拿到每日冠軍 👑」、「Roblox 最考驗友情的遊戲」
- 說明欄放遊戲連結，加上 `#roblox #robloxgame #obby`。
- 每週固定發 2 到 3 支，比一次發很多支有效。

## 16. 怎麼把 Robux 換成現金

**條件：**
- 滿 **13 歲**
- 帳號裡有至少 **30,000 個「賺來的」Robux**（買來的不算），大約可以換 **114 美元**
- Email 已驗證、帳號沒有違規

**怎麼申請：** 存到 30,000 之後，到 Roblox 網站的 Robux 頁面找 **Cash Out（提領）／DevEx**，照指示填資料（需要稅務資料和收款帳戶）。詳細規定看官方說明：<https://create.roblox.com/docs/production/monetization/developer-exchange>

> 遊戲賣出的錢，Roblox 會先扣手續費，你大約拿到售價的 **70%**。例如有人買了 R$100 的東西，你約得到 70 Robux。

## 17. 遇到問題怎麼辦

| 問題 | 解決方法 |
|---|---|
| 按 Play 後什麼都沒有，一片空白 | 看 Output 欄有沒有紅字，把紅字整段複製給我 |
| 金幣每次都歸零 | 第 8 步的 **Enable Studio Access to API Services** 沒打開 |
| 按購買沒反應 | 已經填了商品 ID，但通行證沒打開「Item for Sale」（第 10-1 步第 5 點） |
| 排行榜一直是空的 | 正常，要有人通關後等約 2 分鐘才會更新；而且要發布後才會運作 |
| 某一關真的跳不過去 | 截圖給我，告訴我是哪一關、第幾段、長什麼樣子 |
| 關卡門顯示「🔒 先過前一關」 | 正式遊戲裡每天要先通過前一關。在 Studio 測試時，確認 `Config.StudioUnlockAll` 是 `true` |
| 排行榜寫「publish the game」 | 還沒發布，或沒打開 API 存取（第 8 步） |
| 一直沒有每分鐘加分 | 要**今天**先通過任何 1 關才會開始；每天早上 8 點換日後要再通過 1 關 |
| 吊在鎖鏈上爬不上來 | 按住跳躍或畫面上的「⬆ 爬上去」；如果還是太難，告訴我，或把 `Config.ClimbSpeed` 調大（目前 16） |
| 鎖鏈拉力太強或太弱 | 告訴我是哪一種，或自己改 `Config` 裡的 `ChainDragSpeed`（被拖的速度，目前 6）和 `ClimbSpeed`（往上爬的速度，目前 9） |

### 怎麼把錯誤訊息給我

1. 在 **Output** 欄找到**紅色**的文字。
2. 用滑鼠選取整段紅字 → 按右鍵 → **Copy（複製）**。
3. 貼給我，並說明你當時在做什麼（例如「兩個人站上叢林關的雙人踏板之後」）。

## 18. 我之後改了遊戲，你要怎麼更新

我每次修改都會給你一個新的 `ChainedTower.rbxl`。更新方法：

1. 下載新的 `ChainedTower.rbxl`（一樣用[第 2 步](#2-下載遊戲檔)的連結）。
2. 在 Studio 打開它（File → Open from File）。
3. **先測試**：按 Play 確認沒問題。
4. 按 **File** → **Publish to Roblox As...（另存發布）**。
5. **選你原本的遊戲「Chained Tower 綁腳塔」**（不要建新的！）→ 選它的 place → **Overwrite（覆蓋）**。
6. 完成，玩家下次進遊戲就是新版本。

> ⚠️ **商品 ID 會不會不見？**
> 如果你用的是[第 11 步方法 A](#方法-a最簡單把-id-傳給我)（ID 給我填），我給你的新檔案已經包含 ID，不會不見。
> 如果你是自己填的，**請把 ID 也傳給我一份**，不然新檔案裡的 ID 會是 0。

建議先不要，等上線一兩週看完玩家數據再決定，到時候跟我說一聲就能加。
