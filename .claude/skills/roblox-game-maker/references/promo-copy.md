# Promo copy (YouTube Shorts / TikTok / Reels / Roblox)

Write in 台灣繁體中文, plus an English variant on request or for global reach.
Base every claim on what is actually in the video and the game.

## What the Shorts algorithm rewards

- Viewers not swiping away in the first 2 s → the title and first frame must
  explain the hook instantly (a relatable / funny friend situation beats a
  feature list).
- Completion and replays → keep 15–40 s.
- Comments → end with a question; pin a multiple-choice comment.
- Search → put the keywords (Roblox, obby, the game name) in the first line of
  the description.

## Template

**Titles (offer 3, recommend one; ≤ 40 visible characters, emoji at the end):**
1. Friendship / disaster hook — 「被朋友用鎖鏈綁住爬塔，他掉下去我也要陪葬😭 #roblox」
2. Plain mechanic — 「Roblox 新遊戲：腳被鎖鏈綁著還要一起闖關🔗」
3. Challenge — 「這關要兩個人一起跳才過得去…你和朋友過得了嗎？🔗 #roblox」

**Description:**
```
<一句話類型＋遊戲名，例如：Roblox 雙人／四人鎖鏈闖關遊戲 🔗 Chained Tower 綁腳塔>

<2–3 行最好笑或最特別的機制>

✅ <賣點 1>
✅ <賣點 2>
✅ <賣點 3>

👉 Roblox 搜尋「<遊戲名>」
https://www.roblox.com/games/<placeId>

<留言問題，例如：你會選誰當你的綁腳隊友？留言標記他 👇>

#roblox #robloxobby #obby #robloxgame #<中文遊戲名>
```
3–5 hashtags only (more than 15 voids them all; 3–5 precise ones work best).

**Pinned comment (post right after publishing, then pin):**
```
1️⃣ <選項 A>
2️⃣ <選項 B>
3️⃣ <好笑的選項 C 😂>
你是哪一種？留數字 👇
```

**English variant:** same structure, e.g.
「Chained to my friend in Roblox… if he falls, I fall 😭 #roblox」.

## Posting tips to include

1. Only post once the game is public.
2. Pick a cover frame that shows the core mechanic clearly (e.g. two players
   and the chain).
3. Reply to every comment in the first hour; ask friends to watch fully, like
   and comment.
4. Taiwan students: 17:00–21:00, Fri/Sat evenings best.
5. Make a series instead of reposting (fails, records, first-time reactions),
   2–3 a week, 15–30 s each.
6. On TikTok / Reels swap in a trending in-app sound.

## Roblox game page text

Short, scannable, bilingual if the audience is mixed: one-line hook, 3–5
bullet features, how to play with friends, update cadence (e.g. "new routes
every day"). No fake urgency ("限時" when it isn't) — Roblox policy forbids it.
